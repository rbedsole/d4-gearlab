# D4 GearLab

Mobile-first Diablo IV gear comparison tool.

## v0.1

This first build is a phone-testable prototype of the deterministic comparison engine. The Stinger Spiritborn profile and displayed affix values are fixtures, not live Diablo IV roll-range data.

### Current behavior
- Equipped vs candidate comparison
- Required, priority, and desired affix semantics
- Greater Affix awareness
- Current Quality / temper investment kept separate from intrinsic item quality
- Upgrade, Keep for Development, Sidegrade, Downgrade, and No Meaningful Upgrade verdicts

Next: connect canonical current Diablo IV data and build-profile importing before treating results as live-game recommendations.
